Selamat Datang

Ini adalah contoh menu navigasi responsif menggunakan CSS Flexbox dan Media Query. Pada desktop, menu tersusun secara horizontal di bagian atas. Ketika dibuka pada tablet dan smartphone, menu berubah menjadi susunan vertikal di samping kiri.

Tampilan saat ini: desktop Tampilan saat ini: tablet Tampilan saat ini: smartphone

Desktop

Lebar layar di atas 900px. Menu horizontal di atas dengan flex-direction: row.

Tablet

Lebar layar 601px sampai 900px. Menu vertikal di samping kiri dengan flex-direction: column.

Smartphone

Lebar layar maksimal 600px. Menu tetap vertikal di samping kiri dengan lebar yang lebih ramping.

Ubah ukuran jendela browser untuk melihat perubahan menu.
